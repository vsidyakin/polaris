# Phaser3-Road — third-party source

The Mercury easter egg (SOLAR CIRCUIT, `#egg8`) ports its **engine** from
**Phaser3-Road** by James Simo — https://github.com/jamessimo/Phaser3-Road —
at commit `21acaacf8bf9da7b71f7ea303e5bd06fd9102934` ("Cleanup for public
consumption", 28 Apr 2019).

That project is itself a Phaser 3 port of **javascript-racer** by Jake Gordon
(Code inComplete) — https://codeincomplete.com/articles/javascript-racer/ — and
was scaffolded from Photon Storm's `phaser3-project-template`.

it when the review chrome comes out at launch.

## None of the artwork is upstream's

**Every PNG in this directory is generated by
`scripts/build-solar-road-art.mjs`.** Run that script to change the art and
commit what it writes; the build never invokes it.

| File | What it is |
| :--- | :--------- |
| `sky.png` | 1600×360, tiles horizontally. Star field, coronal streamers, the sun's limb on the horizon. |
| `ridge.png` | 1600×200, tiles horizontally. Three depth bands of crater rim and scarp. |
| `vector*.png` | 88×58 ×5. VECTOR, the balanced craft: a Mersive hovercraft seen from behind and slightly above, floating clear of the ground on twin thrusters. The five are level, banking left and right, and banking hard left and right — rolled, nose yawed into the turn, outboard thruster flared. |
| `lance*.png` | 88×58 ×5. LANCE, narrower and copper. Same five frames. |
| `bulwark*.png` | 88×58 ×5. BULWARK, wide-set and green. Same five frames. |
| `plume.png` | 44×64. The exhaust flame layered over the one baked into the frames above and scaled with speed. |

All fifteen craft frames are the same size, which is load-bearing rather than
tidy: `car.ts` swaps them on a live sprite whose resting Y came from the frame
height, so a taller frame would make the craft hop.


Upstream's four images were **deleted, not kept**: `carSingle.png` is a purple
car with PHASER written across its boot, `Billboard.png` and `logo.png` are the
Phaser wordmark, and `background.png` is a blue sky over green hills. The first
three are that project's branding and the fourth is the wrong planet.
`grassStrips.png` and `stripes800x32-v2.png` went with them — upstream loads
neither.

The two backdrop layers **tile horizontally**, which is the constraint that
shapes the generator: they are `TileSprite`s scrolled with `tilePositionX`, so
every horizontal feature is generated as a function of an angle around the full
width rather than of x. Break that and a seam walks across the sky every 1600px
of travel.

## What was not ported

- `src/scenes/titleScene.js` and `src/classes/playerCar.js` are both zero-byte
  files upstream — placeholders that were never written.
- `src/indexDEP.js` is the pre-refactor single-file version, superseded by the
  scene/class split it sits next to. Porting it would have meant shipping the
  same game twice.
- The webpack, Babel and Electron build config, which this repo's Astro/Vite
  pipeline replaces.

## Where the port deviates, and why

Each of these is commented at the point it happens; this is the index.

| Change | Where | Why |
| :----- | :---- | :-- |
| Own keyboard handling, Phaser's capture disabled | `input.ts` | Phaser captures on `window` for the life of the game, which would outlive the overlay and swallow the browser's shortcuts. |
| Mount/destroy handle | `index.ts` | Upstream builds one `Phaser.Game` at module scope and never tears it down. This egg opens and closes repeatedly. |
| Explicit `import Phaser` in the scenes | `boot-scene.ts` | Phaser's types are an ambient global but its ESM build sets no global, so a bare `Phaser.Scene` type-checks and then throws. |
| Colours as numbers, Mercury palette | `render-helpers.ts` | Upstream's were strings; and a blue sky is the wrong planet. |
| Per-segment road width | `game-scene.ts` | Upstream's road is one fixed width for the whole track. |
| `n + 1` in `addRoad`'s easing | `game-scene.ts` | Upstream eases a segment's *end* point at `n/total`, so no piece reaches its target height and the residue accumulates into a jolt at the loop seam. |
| Parallax backdrop | `game-scene.ts` | Upstream plants one static sprite, so the horizon is nailed to the screen however hard you turn. |
| Off-road penalty and grip build-up | `car.ts` | Upstream declares `offRoadDecel` and `offRoadLimit` and reads neither, so leaving the road costs nothing. |
| Roadside props removed | `game-scene.ts` | See above — they are Phaser branding. The placement machinery is intact. |
